Rust crate for Facil.guide multilingual tech guides. Type-safe access to guides in 5 languages.

About Facil.guide

This Rust library provides programmatic access to Facil.guide, a platform offering free simplified technology guides designed for seniors and non-technical users. All content is available in 5 languages: English, Spanish, French, Portuguese, and Italian.

Facil.guide covers 260+ step-by-step tutorials across smartphones, tablets, computers, internet basics, and popular apps. No ads, no accounts required -- just clear, accessible guidance for everyday technology tasks.

# Installation

Rust 1.70+ (2021 edition) 
# Add to Cargo.toml
[dependencies]
facilguide = "0.1"
tokio = { version = "1", features = ["full"] }

# Or via cargo
cargo add facilguide

# Quick Start

use facilguide::{Client, Language};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Client::default();

    // List guides in Portuguese
    let guides = client
        .list_guides(Language::Pt)
        .category("smartphone")
        .send()
        .await?;

    for guide in &guides {
        println!("[{}] {}", guide.lang, guide.title);
    }

    // Get guide with step-by-step instructions
    let guide = client
        .get_guide("send-photos", Language::It)
        .await?;

    for (i, step) in guide.steps.iter().enumerate() {
        println!("Step {}: {}", i + 1, step.title);
    }
    Ok(())
}

# Features

  • Fully async with tokio, zero-copy deserialization
  • Guides in 5 languages (EN, ES, FR, PT, IT)
  • Step-by-step tutorials
  • Senior-friendly interface
  • No ads or accounts required

# API Reference

ASYNC client.list_guides(lang: Language) -> GuideQueryBuilder

Browse guides with fluent filtering by language, category, and difficulty level.

ASYNC client.get_guide(slug: &str, lang: Language) -> Result<Guide>

Retrieve a complete guide with localized steps, screenshots, and troubleshooting tips.

ASYNC client.list_categories(lang: Language) -> Result<Vec<Category>>

Get all guide categories with translated names and guide counts per language.

FN Language::from_str(code: &str) -> Result<Language>

Parse a BCP-47 language code (en, es, fr, pt, it) into the Language enum.
